سیستمی پێشکەوتووی فێد و بازاڕ (V8 Pro)

داتاکانی ماکروو (ئێستا، پێشبینی، پێشوو)

نیشاندەر ئێستا پێشبینی پێشوو
داتای پێشەنگ و کاریگەر (Leading Indicators)
ISM Manufacturing PMI
نیشاندەری چالاکی بەرهەمهێنان؛ بەرزبوونەوەی سەروو ٥٠ ئاماژەیە بۆ گەشە و پێشوەختە فشار دەخاتە سەر بەرزبوونی CPI و NFP.
Value
ADP Employment (هەلی کاری کەرتی تایبەت)
پێشبینیکەری سەرەکی NFP؛ گەشەی خێرای ئەمە کاریگەری ڕاستەوخۆی هەیە لەسەر بەهێزی بازاڕی کار و بڕیاری سودی فێد.
Value
JOLTS Job Openings (دەرفەتەکانی کار)
ژمارەی کارە بەردەستەکان؛ زۆر بوونی دەبێتە هۆی بەرزبوونی مووچە و لە ئەنجامدا بەرزبوونی Core PCE و CPI.
Value (M)
Michigan Inflation Expectations (چاوەڕوانی هەڵاوسان)
ڕێژەی پێشبینی خەڵک بۆ هەڵاوسان؛ بەرزبوونی وا لە بەکاربەر دەکات زووتر خەرجی بکەن (Retail Sales) و هەڵاوسانی ڕاستەقینە بەرز دەکاتەوە.
Value (%)
٨ داتای سەرەکی و بنەڕەتی فێد (Core Fed Indicators)
هەڵاوسانی گشتی (Headline CPI)
پێوەری سەرەکی هەڵاوسانی نرخەکان بۆ بەکاربەر؛ کاریگەری ڕاستەوخۆی هەیە لەسەر بڕیاری دەستبەجێی سودی فێد.
Value
هەڵاوسانی بنەڕەتی (Core CPI)
نرخەکانی خۆراک و وزەی لێ دەرچووە؛ فێد بە وردی چاودێری دەکات بۆ زانینی جێگیری هەڵاوسان.
Value
هەڵاوسانی Core PCE (پەسەندترین پێوەری فێد)
ئامانجی سەرەکی فێد گەیاندنی ئەم نیشاندەرەیە بە ٢٪؛ کاریگەرترین داتایە لەسەر بڕیاری کۆتایی سودی بانکی.
Value
هەلی کاری نوێ (Non-Farm Payrolls - NFP)
ژمارەی کارە زیادبووەکان لە دەرەوەی کشتوکاڵ؛ گەشەی زۆر مانای بەهێزی بازاڕی کار و پێویستی بە ڕێژەی سودی بەرز دەگەیەنێت.
Value
ڕێژەی بێکاری (Unemployment Rate)
ڕێژەی بێکاری لە بازاردا؛ بەرزبوونەوەی نیشانەی خاوبوونەوەی ئابوورییە و فێد ناچار دەکات سود کەم بکاتەوە.
Value
هەڵاوسانی بەرهەمهێنەر (PPI)
نرخەکانی کاڵا لە قۆناغی بەرهەمهێناندا؛ پێشوەختە ئاگاداری گۆڕانکاری نرخەکانە بۆ بەکاربەر (CPI).
Value
فرۆشتنی تاکەکەسی (Retail Sales)
قەبارەی خەرجی و کڕینی بەکاربەران؛ گەشەی خێرا فشار دەخاتە سەر بەرزکردنەوەی هەڵاوسان.
Value
گەشەی GDP (تێکڕای بەرهەمی ناوخۆیی)
پێوەری گشتی تەەندروستی ئابووری وڵات؛ گەشەی بەهێز ڕێژەی سودی بەرزی لەسەر دەهێڵێتەوە.
Value
